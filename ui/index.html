Google Cloud SDK & Local Environment Setup
Zero Auth Tokens Required

Connect Python, Node.js, Go, Terraform or the Google Cloud CLI (`gcloud`) directly to Aura-GCP:

# Configure standard Google Cloud Emulator environment variables
export STORAGE_EMULATOR_HOST=http://localhost:8080
export PUBSUB_EMULATOR_HOST=localhost:8080
export FIRESTORE_EMULATOR_HOST=localhost:8080
export CLOUDSDK_CORE_PROJECT=local-project

# Test with curl or your preferred Google Cloud client
curl -s http://localhost:8080/storage/v1/b?project=local-project
